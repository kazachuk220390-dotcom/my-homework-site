Контактная ссылка открывает существующий официальный сайт, не передавая ему план.

## Размещение

Планируемый сервис — GitHub Pages в существующем репозитории владельца `kazachuk220390-dotcom/my-homework-site`, без собственного домена. Публичная проверочная ссылка **пока не подтверждена**. Включение Pages и проверка опубликованной страницы требуют доступа к GitHub API и хосту Pages.

Нужные сетевые дополнения сохранены в черновике среды: `sumnauka.ru`, `www.sumnauka.ru`, `api.github.com`, `kazachuk220390-dotcom.github.io`. Сохранение черновика не применяет политику и не публикует сайт. Нужно просмотреть и сохранить изменения в настройках среды, затем опубликовать среду; после этого повторить заблокированные операции. Новые токены в чат не нужны.

После предоставления доступа: проверить права на репозиторий; включить Pages из `main` / корня; дождаться сборки; прочитать фактический `html_url` сервиса; открыть его отдельно, проверить страницу, ресурсы и выбор пакета на этом адресе. Только тогда записывать актуальную ссылку. Для Pages при отсутствии API-доступа владелец может выбрать источник в **Settings → Pages → Deploy from a branch → main → / (root)** и сообщить адрес из интерфейса; его также нужно проверить.

Метатег `noindex, nofollow, noarchive` и `robots.txt` просят поисковики не индексировать макет. Они не обеспечивают приватность: размещённый на публичном Pages сайт доступен любому, кто знает адрес.

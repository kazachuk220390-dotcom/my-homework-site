# Яндекс Форма: скрытые детали заказа и проверка письма

Проект: https://wownauka.ru/ · существующая форма: https://forms.yandex.ru/u/6af2edf32c4f89fce97e11a8/

Сайт передаёт параметры в URL iframe и запасной ссылки. Чтобы они сохранялись в ответе и уведомлении, нужны настройки **в аккаунте владельца Яндекс Форм**, перечисленные ниже. Одной передачи параметров в адресе недостаточно. Получение письма не подтверждено до реального теста.

## 1. Четыре видимых вопроса

- Имя — обязательный.
- Телефон — обязательный.
- Предполагаемая дата — необязательный.
- Отдельное согласие на обработку персональных данных — обязательное, без предвыбора.

Существующий вопрос «Какая программа Вам понравилась?» сделайте скрытым и необязательным. Его можно сохранить для истории ответов. Для программ, которые уже есть в его вариантах, сайт продолжает передавать прежние ID. Для отсутствующих программ сайт не выбирает другой вариант вместо них. Полное название любого выбранного шоу сохраняется через скрытые текстовые вопросы ниже.

## 2. Скрытые вопросы

Создайте по одному вопросу типа **Короткий текст**, включите **Скрытый вопрос** и в поле **Идентификатор вопроса** вставьте значение из первой колонки. Не делайте служебные вопросы обязательными: общая кнопка «Оставить заявку» допускает обращение без предварительного выбора в калькуляторе.

| Идентификатор | Название вопроса |
| --- | --- |
| `plan_package` | Пакет |
| `plan_program` | Выбранная программа |
| `plan_show` | Научное шоу |
| `plan_format` | Формат праздника |
| `plan_workshops` | Мастер-классы |
| `plan_group` | Количество участников |
| `plan_price` | Предварительная стоимость |
| `utm_source` | Рекламный источник |
| `utm_medium` | Рекламный канал |
| `utm_campaign` | Рекламная кампания |
| `utm_content` | Рекламное объявление |
| `utm_term` | Ключевое слово |

При желании добавьте скрытый `request_origin`: `calculator` означает заявку из калькулятора, `site` — общую заявку. Для общей заявки поля плана намеренно пусты: сайт не выдаёт исходные настройки калькулятора за выбор клиента.

В пакете «Научный переполох» сохраняется его действующее общее научное шоу. Крио-мороженое включено и явно указано среди мастер-классов; лизуны добавляются только при выборе. Для группы более 150 детей и «Сумасшедшей кухни» сохраняется сообщение об индивидуальной стоимости, а не вымышленная сумма.

## 3. Уведомление организатору

В существующей интеграции отправки письма:

1. Проверьте получателя: `j_kaz@mail.ru`.
2. В теле письма через кнопку выбора переменных добавьте **Форма → Ответы на вопросы**. Выберите контактные вопросы и все скрытые вопросы из таблицы.
3. Добавьте **Запрос → Все GET-параметры** как технический резерв для диагностики; имена и телефоны сайт в URL не добавляет.
4. Сохраните интеграцию и изменения формы.

Сайт не может менять настройки стороннего iframe и не подтверждает отправку заявки или доставку письма при простом открытии формы. Клиент самостоятельно заполняет и отправляет Яндекс Форму.

## 4. Сквозной тест после публикации

Откройте https://wownauka.ru/?utm_source=qa&utm_medium=test&utm_campaign=revision-010&utm_content=blue&utm_term=cryo#planner

Выберите:

- Пакет: **Научное шоу**.
- Программа: **Большое Криошоу**.
- Число детей: **До 20 детей**.
- Дополнения: **Крио-мороженое** и **Лизуны**.
- Ожидаемая стоимость: **16 000 ₽** = 10 000 + 3 500 + 2 500.

Нажмите «Хочу такой праздник», укажите имя «ТЕСТ сайта — не бронировать» и свой номер для проверки, дату можно оставить пустой. Согласие выбирается вручную. Отправьте один тест.

Проверьте в ответах формы и в письме:

- контактные ответы;
- пакет «Научное шоу» и программа «Большое Криошоу»;
- оба мастер-класса;
- группа «До 20 детей»;
- стоимость «16 000 ₽»;
- все пять UTM-меток из ссылки;
- отсутствие дополнительного видимого вопроса о программе.

Проверьте папку «Спам», если письма нет. Наличие ответа в форме и доставка письма — разные проверки. Подтверждение получения делает владелец почтового ящика. Тестовая заявка не считается заказом.

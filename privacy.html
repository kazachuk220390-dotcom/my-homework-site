Политика обработки персональных данных

Информация об обработке данных при обращении по поводу научных шоу и детских праздников.

Оператор: Новосельцева Юлия Александровна, физическое лицо, применяющее специальный налоговый режим «Налог на профессиональный доход» (самозанятая).
Контакт для обращений: j_kaz@mail.ru.
Сайт: https://wownauka.ru/.

1. Общие положения

Настоящая Политика описывает обработку персональных данных пользователей сайта «Сумасшедшая наука» по адресу https://wownauka.ru/ при отправке заявки на научное шоу или праздник. Она составлена с учётом Федерального закона от 27.07.2006 № 152-ФЗ «О персональных данных».

2. Какие данные обрабатываются

При заполнении формы заявки пользователь сообщает имя (или предпочитаемое обращение), номер телефона, выбранную программу и, по желанию, предполагаемую дату мероприятия. Также фиксируется выраженное пользователем согласие на обработку данных. Не просим сообщать сведения о здоровье и другие специальные категории персональных данных, а также данные детей.

При посещении сайта и использовании внешней формы технические данные о соединении могут обрабатываться поставщиками соответствующих сервисов согласно их условиям. Если посетитель перешёл на сайт по ссылке с UTM-метками (utm_source, utm_medium, utm_campaign, utm_content, utm_term), эти значения передаются вместе с адресом встроенной формы в сервис «Яндекс Формы», чтобы в дальнейшем можно было учитывать источник обращения. Для сохранения этих меток непосредственно в заявке потребуется отдельная настройка полей формы.

3. Для чего обрабатываются данные

Данные используются для рассмотрения обращения, уточнения условий мероприятия, подготовки предложения и связи с заявителем по его запросу. На основании заявки не оформляется согласие на рекламную рассылку: для неё при необходимости будет запрашиваться отдельное согласие.

4. Основания и действия с данными

Основание обработки данных, предоставленных через форму, — отдельное согласие пользователя. Обработка включает получение, запись, хранение, систематизацию, использование для ответа, уточнение и удаление информации в пределах заявленной цели, а также иные действия, необходимые для её достижения и допустимые законодательством.

5. Сервисы и доступ к данным

Для сбора заявок используется сервис «Яндекс Формы». Согласно условиям сервиса Яндекс и создатель формы выступают самостоятельными операторами персональных данных пользователей, которые заполняют форму. Уведомления о поступивших заявках направляются на электронную почту j_kaz@mail.ru с использованием почтовой инфраструктуры. Публичная часть сайта размещена на GitHub Pages; сами ответы формы не публикуются в репозитории сайта.

Информация используется для ответа на обращение. Доступ к заявкам должен предоставляться только лицам, которым он необходим для обработки обращений.

6. Хранение и удаление

Сведения хранятся в течение времени, необходимого для рассмотрения заявки и переписки по ней, либо в течение другого срока при наличии самостоятельного законного основания для хранения. При достижении цели обработки или отзыве согласия данные подлежат прекращению обработки и удалению в предусмотренном законом порядке, если отсутствуют иные правовые основания.

7. Права пользователя

Пользователь может запросить информацию об обработке своих данных, их уточнение или удаление, а также отозвать согласие. Для обращения напишите на j_kaz@mail.ru. При рассмотрении запроса оператор вправе запросить сведения, необходимые для подтверждения того, к какой заявке относится обращение.

8. Меры защиты

Передача данных с сайта осуществляется по защищённому соединению HTTPS. Доступ к аккаунтам, в которых хранятся заявки, ограничивается средствами авторизации. Для снижения рисков не следует передавать в форме лишние персональные данные.

9. Изменения

При изменении состава формы, сервисов или целей обработки Политика может быть обновлена. Актуальная версия публикуется по адресу https://wownauka.ru/privacy.html.

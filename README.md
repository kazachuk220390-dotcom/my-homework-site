### Запуск

Нужен Python 3. В корне репозитория:

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory .
```

Это локальный сервер для разработки, а не ссылка для куратора. Установка зависимостей для работы сайта не требуется. Все ресурсы включены в проект; внешних шрифтов, библиотек и запросов к API нет.

### Браузерные проверки

Node.js 22+ и Python 3; тесты используют Playwright и Chromium:

```sh
npm ci --ignore-scripts
npx playwright install chromium
npm test
```

Если Chromium уже установлен системно, тесты используют `/usr/bin/chromium`; можно задать другой путь через `CHROMIUM_PATH`. При наличии системного браузера установка браузера Playwright не нужна. Тесты самостоятельно запускают временный локальный HTTP-сервер. В ограниченной облачной песочнице для локальных сокетов и Chromium может потребоваться разрешённое выполнение за её пределами.

### Пакет публикации

До упаковки можно отдельно проверить размеры и отсутствие base64, не выводя содержимое файлов:

```sh
python3 scripts/check_assets.py
```

Проверка допускает до 400 КиБ на изображение и до 3 МБ суммарно для публичных файлов. Компактный отчёт с размерами и хешами сохраняется в `release/asset-report.json`. Упаковка также запускает эту проверку; при ошибке до сборки предыдущий рабочий архив сохраняется.

```sh
python3 scripts/package_site.py
```

Результат текущей версии: `dist/` и `release/sumnauka-review-v0.7.zip`. Архив содержит только публичные файлы сайта, без документов курса, исходных вложений, тестов и зависимостей. Его можно разместить на согласованном статическом хостинге, сохранив структуру файлов.

Фотографии подключены отдельными файлами из `assets/photos/`, без base64. Полученные от владельца семь оригинальных JPG в `assets/` сохранены без изменений; на странице используются шесть выбранных в части 3 кадров. Для них подготовлены компактные WebP-копии в согласованной сине-белой гамме. Список публичных ресурсов для проверки и ZIP задан в `site-assets.json`: многомегабайтные оригиналы в архив не включаются и страницей не запрашиваются. Любое новое изображение, используемое в HTML/CSS, нужно добавить в манифест. Снимки проверочной страницы в `release/` не входят в сайт. В ответах передавать ссылки и размеры, не бинарное содержимое.

Проверочная ссылка, переданная владельцем: https://kazachuk220390-dotcom.github.io/my-homework-site/. Загрузку опубликованной страницы из облачной среды пока не удалось проверить из-за сетевого ограничения. Для GitHub Pages используется источник **Deploy from a branch → main → / (root)**. Файл `.nojekyll` отключает ненужную обработку Jekyll. Включение Pages и наличие рабочей публичной ссылки требуют отдельной проверки; одна отправка файлов в GitHub не означает публикацию.
